# Thomas Jenkins — Operations & Analytics Consulting

This repository now hosts the professional consulting homepage at the **root**, replacing the prior spreadsheet-builder product.

## Deploy to Cloudflare Pages

- Production branch: `main` (after PR approval and merge)
- Build command: `npm run build`
- Output directory: `dist`
- Root directory: repository root
- Existing Cloudflare Pages project can be reused, subject to confirming its build settings and domain mappings.

## Email

Use `tom@thomas-jenkins.net` as the primary mailbox. `hello@` and `automation@` can be aliases. The homepage mailto link currently points to `tom@` and will not accept inquiries until the mailbox is created.

1. Review claims, pricing, and scope.
2. Create and test the Google Workspace mailbox.
