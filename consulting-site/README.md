# Thomas Jenkins consulting landing page

Static, zero-build landing page intended for Cloudflare Pages.

## Deployment
Create a separate Cloudflare Pages project connected to this repository, choose production branch `main` after merging, set build command to blank, and output directory to `consulting-site`. Connect `thomas-jenkins.net` only after reviewing existing DNS/subdomains.

## Before launch
- Set up and verify `consulting@thomas-jenkins.net` (currently a placeholder mailto destination).
- Review copy, fixed-scope offer, and professional claims.
- Add privacy notice and a form backend if replacing mailto with a contact form.
- Do not modify the existing spreadsheet builder deployment; this folder is separate.
